# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). The linked text is authoritative; this is a summary.

We want participation to be harassment-free for everyone. Be respectful and constructive, assume good faith, and keep discussion focused on making the reference accurate and useful. Harassment, insults, sexualized content directed at participants, publishing others' private information, and deliberately misrepresenting sources are not acceptable.

This repository discusses fictional archetypes, some of which involve dark themes (for example yandere). Discuss them as fiction. Do not use project spaces to target or diagnose real people.

Report problems privately to the maintainer through the contact details on the [maintainer's GitHub profile](https://github.com/garretewilliams). Reports are handled confidentially. Maintainers may remove contributions or restrict participation in line with the Contributor Covenant's enforcement guidelines.
